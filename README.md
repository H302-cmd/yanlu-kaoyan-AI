# 🎓 研途助手 · 考研择校与复习进度管理

> 一个面向考研学生的**纯前端**网页工具，提供智能择校、复习进度管理和数据看板三大功能。
> 无需后端、无需数据库，所有用户数据保存在浏览器本地（localStorage），可直接部署到 GitHub Pages。

---

## 一、项目简介

考研信息高度不对称：择校靠猜、复习进度靠手工记录。本项目把这两件事做成一个轻量网页工具：

- **智能择校**：选择专业、填写目标分数，系统基于示例院校库，自动把院校分为「冲一冲 / 稳妥 / 保底」三档；
- **复习进度管理**：添加复习任务、勾选打卡、查看完成率，数据本地持久化；
- **数据看板**：用 Chart.js 自动生成各科任务分布、完成情况、阶段分布图表。

技术栈：**HTML + CSS + 原生 JavaScript + Chart.js**，纯前端实现，无任何构建步骤。

---

## 二、功能说明

| 模块 | 功能 |
|---|---|
| 🎯 智能择校 | 按专业、目标分数、地区、本科背景、其他偏好筛选院校，自动分「冲 / 稳 / 保」三档；支持识别「其他偏好」中的地区关键词 |
| 📅 复习进度 | 添加 / 删除任务，勾选打卡；实时统计总任务数、已完成数、完成率；数据存入 localStorage，刷新不丢失 |
| 📊 数据看板 | 柱状图（各科任务数）、环形图（完成情况）、饼图（阶段分布），随任务数据实时更新 |
| ⚠️ 免责声明 | 页脚明确标注数据为示例，不构成报考建议 |

## 三、本地运行方法

> ⚠️ 由于浏览器安全策略，`fetch('school_data.json')` **不能通过双击 index.html（file:// 协议）加载**，需要用一个本地静态服务器打开。任选一种：

**方式 A：Python（推荐）**
```bash
# 在项目目录下执行
python -m http.server 8000
# 然后浏览器访问 http://localhost:8000
```
> Python 2 用户请用 `python -m SimpleHTTPServer 8000`

**方式 B：VS Code Live Server**
安装 Live Server 插件，右键 `index.html` → "Open with Live Server"。

**方式 C：Node.js**
```bash
npx serve .
```

## 四、GitHub Pages 部署步骤

1. 在 GitHub 新建一个仓库（如 `yanlu-kaoyan`）。
2. 把本项目的 5 个文件（`index.html`、`style.css`、`main.js`、`school_data.json`、`README.md`）上传到仓库根目录。
3. 进入仓库 **Settings → Pages**。
4. **Build and deployment** 中：
   - Source 选择 **Deploy from a branch**；
   - Branch 选择 `main`，目录选 `/ (root)`；
   - 点击 Save。
5. 等待 1–2 分钟，访问 `https://你的用户名.github.io/仓库名/` 即可。

> 首页入口必须是仓库根目录的 `index.html`，所有路径均为相对路径，无需任何配置。
